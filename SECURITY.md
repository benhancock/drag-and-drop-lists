# Security policy

## Reporting a vulnerability

Please report security vulnerabilities privately through GitHub's **Security → Report a vulnerability** flow for this repository. Do not include sensitive details in a public issue.

Include the affected version, reproduction steps, impact, and any suggested mitigation. You can expect an acknowledgment after the report has been reviewed.

## Data handling

Drag and Drop Lists runs locally in the active editor. It does not make network requests, collect analytics, or access the clipboard. See the privacy section in [README.md](README.md) for details.
